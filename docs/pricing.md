# Pricing

## Plans

| Plan | Price | Who it's for |
|------|-------|--------------|
| **Free** | $0 forever | Individual users — full P2P sharing, @handle, encryption |
| **Pro** | $4.99/mo or $49.99/yr | Power users — unlimited pals, relay quota, advanced tools |
| **Team** | $6.99/seat/mo or $69.99/seat/yr | Teams — webhooks, audit export, org/dept management, SSO |
| **Enterprise** | Custom | Organizations — self-hosted discovery, compliance bundles, SLA |

> **Beta note:** All features are currently unlocked for everyone during beta. Paid plan gating will activate when billing launches.

## What's Included

### Free
- Full P2P encrypted file sharing (ChaCha20-Poly1305)
- @handle identity
- E2E encrypted chat
- Pals & groups
- Permissions (ACL)
- PIN lock + auto-lock
- Inbox messages
- Share links
- Activity log
- Folder sync
- 100+ CLI commands
- All extensions included

### Pro ($4.99/mo)
Everything in Free, plus:
- Unlimited pals & shares
- 50 GB relay quota
- Priority TURN relay
- Vanity @handles
- VFS (virtual drive)
- File manager context menu
- Usage analytics
- Delta transfer (block-level)
- Encrypted backup
- API keys

Annual plan: $49.99/year (save 17%)

### Team ($6.99/seat/mo)
Everything in Pro, plus:
- Per-seat billing
- Organization & department management
- SSO / SAML 2.0 / OIDC
- SCIM user provisioning
- Webhooks & automation
- Audit log export
- Team workspaces
- DLP policies & retention rules
- Branded themes
- Dedicated relay
- Priority support

Annual plan: $69.99/seat/year (save 17%)

### Enterprise (Custom)
Everything in Team, plus:
- Private overlay networks
- IP allowlist
- Audit log streaming (SIEM)
- Compliance bundles (HIPAA, SOC2, GDPR...) — see note below
- Self-hosted / custom discovery server
- SLA guarantee
- Dedicated account manager
- Custom contract & invoicing

Contact [hello@palexplorer.com](mailto:hello@palexplorer.com) for Enterprise pricing.

## Extension Tiers

Extensions are gated by subscription plan:

| Tier | Requires | Examples |
|------|----------|---------|
| Free | Any plan | analytics, auth-email, auth-oauth, discovery, email-notifications, explorer-integration, vfs |
| Pro | Pro or above | teams, media-streaming, reporting-dashboard, transfer-analytics, webhook-integrations, relay-server, federation-registry |
| Team | Team or above | sso-connector, scim-provisioning, webhook-integrations, org-policy, federation-bridge |
| Enterprise | Enterprise | enterprise-rbac, advanced-audit, content-scanner, resource-governor, dev-teams, compliance bundles |

See [Extensions](/extensions/) for the full list of all 36 extensions. Compliance bundles are policy-enforcement templates, not audited compliance guarantees — see [Extensions](/extensions/#enterprise) for details.

## Billing

- Billed via Lemon Squeezy (credit card, PayPal)
- Monthly billing — cancel any time
- Paid features are disabled (not deleted) when subscription ends
- Annual plans available: Pro $49.99/yr, Team $69.99/seat/yr (both save 17%)
- Enterprise: contact [hello@palexplorer.com](mailto:hello@palexplorer.com) for custom pricing
